## 二、五条核心教训

### 教训1：数值异常先反查图表，再定性（最重要）
WB将"1×10⁹ N"直接定性为"量级荒谬的验证荷载"。但 GPT 核对发现：图3.31 峰值仅 500 kN
（反推实际输入≈1×10⁶ N，正文属笔误），而图5.9 峰值 5×10⁵ kN 又与 10⁹ N 同量级——两图矛盾。
**正确姿势**（GPT修订版）：写"两处荷载值与对应图线峰值不一致，须核对实际输入、纵轴单位及
程序输出"——不断言，但矛盾本身就是问题。若断言"荒谬"，作者回复"笔误已改"即可化解，反而
损害评审人公信力。

### 教训2：盯住"宣称能力 vs 数学形式"的矛盾
"声称考虑翘曲效应"+ 6DOF 单元 + 刚度阵无 EIω = 原理错误，无法用笔误化解。
这类矛盾是博士论文评审中最硬的伤，优先级最高。审查方法：把论文宣称的能力列清单，
逐项找数学载体（自由度/刚度项/方程项），找不到即矛盾。

### 教训3：规范口径必须原文级核对
"逐支座抗倾覆系数"错误之所以硬，是因为 JTG 3362-2018 的 Kqf 是 Σ 求和的整体系数。
批评规范类问题的前提是自己先把规范定义啃透，并预判作者可能的辩护路径
（如"按全支座有效计算负反力本就是规范做法"），把批评点落在真正站得住的位置。

### 教训4：升华能力 = 把单点问题连成机理链
Gemini 的升华范式：
- 6DOF问题 → Vlasov约束扭转第7自由度 + 畸变 + 剪力滞 + 腹板主拉应力
- 支座负反力 → compression-only接触非线性 + 有效倾覆轴动态迁移 + 刚度退化
- 恒活载二分 → 体系转换后温度次内力 + 支座爬移 + 拉杆高周疲劳
- 车速1m/s → HMT液压均载 + 超高侧倾向轴荷转移
单点错误 + 机理解释 + 工程后果 = 评审意见的说服力。学习这种"错误→机理→后果"三段式。

### 教训5：结论力度必须与缺点力度匹配
Gemini 总评"已达到工学博士学位论文水平，同意修改后答辩"，但其5条缺点条条是核心科学
原理缺陷——重炮轻判。评审结论（同意答辩/修改后答辩/修改后重审）要自问：若缺点全部属实，
这个结论还站得住吗？

## 三、方法论沉淀（已固化进 SKILL.md）

1. 五步阅读流程（提取→骨架→精读→交叉验证→意见生成）
2. 四层审查清单（理论/方法/数据/工程）
3. 笔误三步法（反查图表→量纲核算→分级定性）
4. 多智能体辨析六步（验证→分级→吸收→保留→升华→结论匹配）
5. 固定输出格式（总评不写缺点→能力达标段→缺点和不足→修改建议；每条≤150字附佐证）
